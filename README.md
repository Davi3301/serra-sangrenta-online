# Serra Sangrenta (online)

Jogo de sobrevivência e terror em 2D, visto de cima. Sete dias depois do Grande Tremor, um vale isolado nas montanhas foi tomado pelo Tecido: carne viva que sobe das fendas, aprende a andar e, à noite, chama as pessoas pelo nome.

**▶ Jogar no navegador: https://davi3301.github.io/serra-sangrenta-online/**

Funciona no computador e no celular, sem instalar nada. O progresso fica salvo no próprio navegador.

## Multijogador (até 4 pessoas)

1. Um de vocês clica em **Multijogador → Criar mundo**. O mundo roda no computador dele, então ele deixa o jogo aberto enquanto jogam.
2. Ele clica em **Copiar link** e manda para os amigos.
3. Quem abrir o link cai direto na tela de entrar, com o código da sala preenchido: é só escolher o nome e clicar em **Entrar**.

A conexão é direta entre os jogadores. Ninguém precisa pagar servidor: esta página só entrega o jogo, e o serviço gratuito do PeerJS só ajuda os computadores a se acharem.

Também dá para entrar digitando o código de 5 letras em **Multijogador → Entrar numa sala**, inclusive pela versão do [itch.io](https://dave-3301.itch.io/serra-sangrenta) ou pelo executável de Windows.
